# Patent Claims – Clause Learning Engine

## Independent Claims

1. A system for dynamically recommending contract clauses based on historical user editing behavior, comprising:
   - a clause ingestion module,
   - a redline parser,
   - a feedback loop trained on user interactions, and
   - a ranking engine for clause suggestions.

2. A method of storing and learning from legal clause acceptance or rejection in the context of contracts, wherein suggestions improve over time based on user interaction data.

## Dependent Claims

3. The system of claim 1, wherein clause suggestions are ranked based on document type, jurisdiction, and party roles.

4. The system of claim 1, further comprising an embedding layer that compares clauses semantically using vector similarity.

5. The method of claim 2, wherein clause edits are parsed and converted into training data for an adaptive learning model.

6. The system of claim 1, wherein feedback data is stored by team, organization, and individual user profiles.
